# Making Minecraft Beat Itself

In this project, I will make a solution that uses baritone [and other necessary mods] to autonomously beat Minecraft, without any user input - aside from running a command of course.

## Basic UFD
This UFD is not final, but merely a quick diagram I made as a starting point.
Arrows pointing down are `Yes`, arrows pointing right are `No`.
