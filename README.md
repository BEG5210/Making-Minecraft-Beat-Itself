# Making Minecraft Beat Itself
In this project, I will make a solution that uses [Baritone](https://github.com/cabaletta/baritone) [and other necessary mods] to complete Minecraft without any user input autonomously! aside from running a command of course...

My current plan is to have it beat the ender dragon first. In the future, more options and functionality could be added. i.e, get all acheivements, ect.

## Basic UFD
This UFD is not final, but merely a quick diagram I made as a starting point.
