# Making Minecraft Beat Itself

In this project, I will make a solution that uses baritone [and other nescicary mods] to autonomously beat Minecraft, without any user input - Aside from running a command of course.

## Basic UFD
This image file can be found under `doc/ufd/BasicUFD/png`.

This UFD is not final, but moreso a quick one I made as a start. Arrows pointing down are `Yes`, arrows pointing left are `No`.
